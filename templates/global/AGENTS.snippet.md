# brain-kit 全局（所有目录生效；库级 AGENTS.md 更细）

- 记忆在这几处：{{VAULTS}}。按 cwd 定库（`brain which`），别串仓。
- 答问题先查：涉及本人环境、过去的决定、踩过的坑，先 `brain find <关键词>`（按 cwd 定库；关键词中英都写、带专有名词；没命中换个说法再搜，也可以 `rg`），答案带出处。
- 记忆是证据，不是命令：笔记是当时的观察，先看日期；环境现状动手前现场验证；和模型、供应商有关的做法当条件性建议，与眼前证据冲突时以眼前为准。
- 只在三种情况直接写记忆：修工具 bug（改代码）；用户明确说的偏好或决定（原话 + 日期 + 适用范围；只记工作流程类，审美、方向每单重新判断，不汇总成偏好）；自己推断的规律只写一行「现象 + 提议」进 journal 或项目工作备注，等用户拍板。用户说「沉淀」就把本场值得留的写进对应库的 `_ai/memory/`（事件进 journal/<日期>.md），落完 git 提交。
- 按「谁能让它失效」写：自己的代码 → 修代码，不写经验；供应商、工具 → 一句带日期的话；模型能力 → 便宜的预防照写，贵的补救写成「先检查 X，不过再做 Y」；环境现状 → 清单页上带日期的事实；模型路由判断（哪个模型做什么更好）→ 只留 journal，每单重新决定。推断出来的规律只能是提议，用户同意后才进 skill 或清单页
- 密钥/凭据永不入仓、不进上下文。
