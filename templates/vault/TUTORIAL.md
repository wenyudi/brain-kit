# brain 使用教程 —— 三分钟上手

一句话用法：**打开 Claude 对话，像跟人说话一样说事，系统的事它全包。** 不用记命令、不用建文件、不用整理笔记。

```bash
cd <vault 根> && claude    # 首次部署见 brain-kit README
```

## 日常就这几种说法（全是自然对话）

| 你说 | 发生什么 |
|---|---|
| 说事（做成了什么、踩了什么坑、做了个决定） | AI 过私有性刀后自动沉进 AI 仓，一行轻提示 |
| 问事 | AI 先查 AI 仓和速查再答，带依据 |
| 「沉淀」（任何项目目录都行） | /harvest 把当场会话蒸进 AI 仓 |
| 「这事 X 号前要办」 | AI 仓记任务，到期开场自动提醒 |
| 改了基建 | AI 顺手更新速查清单 |

## 你要看的只有三种东西

- **速查**（`_Private/`）：要用才查的工具书
- **digest**（`digest/`）：每周第一场会话自动送上门的周报，Obsidian 会直接翻到那页
- **常青页**（`pages/`）：同类经验攒够时 AI 会问「够写一篇了，要吗」——你点头才有

别的目录都是机器的，不用管。AI 的记忆和网上收的资料都在 `_ai/`（记忆 `_ai/memory` + 藏书房 `_ai/library`，Obsidian 搜索里已隐藏），永远不用看——收藏的原文全文都留着，想要哪篇直接问 AI 调。

## 手机记东西 / 剪网页

Obsidian 手机端往 `inbox/` 里建笔记随手记（格式随意，不用管 frontmatter），次晨第一场会话自动分流，处理完原文件即删。

网页和 B 站视频用剪藏插件剪进 `inbox/`，每天 06:00 自动搬进藏书房（原文和图片都存本地，不怕链接烂）。剪的时候有话就写一句（弹窗里的 `note`，或笔记里的 `## 我` 段）：为什么收、哪段打动你、学到了什么。写了 AI 才会深读并把你的判断记进记忆；不写就当纯存档，哪天想看再说「消化 X」。

## 什么时候沉淀

不用记。在别的目录聊完的事，夜里会自动捞进记忆；下次开场简报会列「未捞会话」，想现在捞就说「捞 #n」。

## 出问题了

- 开场简报会报：到期任务、inbox 积压、快照/定时器死亡
- 手动体检：`brain lint`
- 部署与机械件说明：brain-kit 的 README；给 AI 的运转合同：`CLAUDE.md`
